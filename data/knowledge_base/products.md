# 商品知识库

## 无线蓝牙耳机

无线蓝牙耳机是一款主动降噪的真无线耳机，支持蓝牙 5.3 协议，单次充电续航 8 小时，配合充电仓总续航可达 30 小时。支持双设备同时连接，可随时在手机与电脑之间无缝切换。耳机采用 Type-C 快充接口，充电 10 分钟可使用 2 小时。配备入耳检测功能，摘下耳机自动暂停播放。价格 399 元。

### 降噪与音质

耳机配备前馈加反馈双麦克风主动降噪，降噪深度最高可达 40dB。支持通透模式，走路或与人交谈时可一键切换，无需摘下耳机。音质方面搭载 10mm 动圈单元，支持 AAC 高清音频解码。

### 防水与续航

耳机本体支持 IPX5 级防水，可防汗水与小雨。充电仓内置 400mAh 电池，支持无线充电与 Type-C 有线充电两种方式。

## 机械键盘

机械键盘为 87 键紧凑布局，支持热插拔轴体，出厂搭载 Gateron 红轴，线性手感，触发力度 45g。键帽采用 PBT 材质，耐磨不打油。支持全键无冲，游戏场景不冲突。键盘支持有线、2.4G 无线、蓝牙三种连接模式，可同时连接 3 台设备一键切换。价格 299 元。

### 灯效与自定义

键盘支持 RGB 动态灯效，可通过驱动软件自定义按键宏、修改灯效模式。内置 4000mAh 电池，关闭灯效后续航可达 200 小时，开灯约 60 小时。

## 智能手表

智能手表配备 1.43 英寸 AMOLED 高清屏，支持血氧、心率、睡眠质量、压力监测。支持 100 多种运动模式，5ATM 防水等级可游泳佩戴。内置 GPS 定位，运动轨迹记录准确。续航 14 天（典型使用），支持磁吸充电。价格 1299 元。

### 健康监测

手表可 24 小时连续监测心率与血氧，支持异常心率提醒与久坐提醒。睡眠监测可分析深睡、浅睡与快速眼动各阶段，并给出睡眠改善建议。

## 便携充电宝

便携充电宝容量 20000mAh，支持 22.5W 双向快充，兼容 PD 3.0 与 QC 4.0 协议，可为手机、平板、耳机快速充电。配备双 USB-A 与一个 USB-C 输出口，可同时为 3 台设备充电。通过航空运输认证，可随身携带上飞机。价格 159 元。

### 充电安全

充电宝内置智能芯片，支持过充、过放、过流、短路多重保护。外壳采用阻燃材料，通过 3C 认证。

## Python 编程入门

《Python 编程入门》是一本面向零基础读者的 Python 教程，覆盖语法基础、数据结构、函数、面向对象编程与文件操作，最后以一个爬虫实战项目收尾。价格 69 元。

### 内容特色

全书共 15 章，配有 120 多个代码示例与练习题，每个章节末尾提供在线练习二维码，读者可扫码在浏览器中直接运行代码。

## 深度学习实战

《深度学习实战》基于 PyTorch 框架，系统讲解深度学习基础与主流模型，涵盖多层感知机、CNN 图像识别、RNN 文本处理与 Transformer 架构，最后一章讲解模型部署与量化。价格 129 元。

### 配套资源

随书附带 GitHub 仓库，包含全部章节代码与数据集下载地址。需要 Python 3.9 以上环境与 PyTorch 2.0 以上版本。

## AI 应用开发实战

《AI 应用开发实战》讲解大模型应用开发全流程，内容包括提示词工程、检索增强生成 RAG、Agent 智能体开发、模型微调与生产环境部署。适合有 Python 基础的开发者阅读。价格 99 元。

### 实践项目

书中包含 8 个可运行的完整项目，如客服机器人、知识库问答系统、数据分析智能体等，均提供源码与部署文档。
